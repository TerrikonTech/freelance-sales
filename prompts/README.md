# Промты

Правил меньше, чем кажется. Здесь всё, что влияет на текст.

## Что лежит рядом

- `response_principles.md` — правила отклика: структура, длина, запреты, финальная строка. Одно правило на строку, строка начинается с дефиса. `#` — комментарий.
- `response_calibration.md` — примеры хороших откликов. Блок начинается с `##`, внутри строки `Пример:` и `Почему:`.
- `ai/` — промты нейросети по шагам. Имя файла = шаг:
  - `lead_analysis_v2.md` — разбор заказа и оценка;
  - `draft_compose.md` — написание отклика;
  - `conversation_turn.md` — ответ в чате;
  - остальные — реже используемые шаги (спецификация, договор, дизайн).

## Как применять

Просто сохрани файл. Больше ничего делать не нужно: правила подхватываются на следующем отклике, промты нейросети — на следующей задаче.

Если файл удалить или он станет пустым, система молча вернётся к встроенному тексту — ничего не сломается.
