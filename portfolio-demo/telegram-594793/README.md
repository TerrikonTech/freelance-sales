# Демо-кейсы для заказа Telegram 594793

Пакет подготовлен для сложной автоворонки Instagram → Direct → Telegram-бот → регистрация → GetCourse → обучение → оплата.

## Статус

- Пять кейсов являются концептами и демонстрационными проектами.
- Реальные клиенты, отзывы, бюджеты, внедрения и достигнутые метрики не заявляются.
- Пакет не опубликован на FL.ru и не предназначен для автоматической загрузки в рабочую БД без отдельного подтверждения владельца.
- Тексты находятся в `cases.json`.
- Спецификации и точные промпты для визуалов находятся в `visual_specs.json`.
- Пять готовых изображений находятся в `images/`, по одному PNG 1672×941 на кейс.
- Контрольные суммы, размеры и фактический статус генератора записаны в `manifest.json`.

## Состав

1. FLOW BRIDGE. Архитектура омниканальной воронки и единая событийная модель.
2. COURSE BOT. Telegram-бот с повторными входами и синхронизацией GetCourse.
3. IDENTITY CORE. Единый профиль, дедупликация и обратимое слияние.
4. FUNNEL RADAR. Событийная аналитика, дашборд и детализация до пользователя.
5. RECOVERY LOOP. Идемпотентные webhooks, очереди, мониторинг и безопасный winback.

## Проверенные технические ограничения

- Instagram Messaging API работает с профессиональным аккаунтом; получатель должен сначала написать этому аккаунту. В webhook используется Instagram-scoped ID, а referral для click-to-Direct может содержать `ref` и `ad_id`.
- GetCourse Import API не позиционируется как оперативное управление объектами.
- GetCourse Export API асинхронный, выполняется в один поток и имеет общий лимит 100 запросов за два часа. Для оперативных событий GetCourse рекомендует callback-вызовы, а экспорт разумно оставлять для сверки.

## Проверка

```bash
python3 validate.py
```

Проверка требует ровно пять кейсов, обязательную маркировку демо, пустые URL до публикации, отсутствие заявленных процентов и наличие пяти визуальных спецификаций. После генерации изображений она также проверит PNG, имена и размер 1672×941.
