# Отправка от имени владельца — работает

Закрывает `BUSINESS_PEER_INVALID`: Bot API пишет только в чаты бизнес-подключения,
а часть диалогов попадает в базу из зеркала личной сессии.

## Как устроено

Сервис **не открывает Telegram**. Отправка от аккаунта владельца уже существует:
`codex-mesh-hermes-mtproto-sync` вычитывает таблицу `mtproto_outbox` и отправляет каждую
строку через `client.send_message`. Этот сервис — мост:

    Postgres (отказ Bot API) -> строка в mtproto_outbox -> существующий отправитель
    результат отправителя  -> журнал доставок, переписка, активности

Второй клиент на той же сессии не создаётся сознательно: это риск
`AUTH_KEY_DUPLICATED` и потери рабочего зеркала. Ни api_id, ни api_hash, ни вход
по коду этому сервису не нужны.

## Предохранители

- берёт только отказы `BUSINESS_PEER_INVALID`, другие ошибки остаются видными;
- сверяет хеш текста с одобренным черновиком;
- id доставки — первичный ключ очереди, повторная постановка невозможна;
- неудача отправителя фиксируется и автоматически не повторяется;
- без `SALES_USERBOT_ENABLED=true` — только холостой режим;
- потолок `SALES_USERBOT_DAILY_LIMIT` (по умолчанию 20) в сутки.

## Команды

    cd freelance-sales-v2
    docker compose -f ops/userbot/docker-compose.userbot.yml build
    docker compose -f ops/userbot/docker-compose.userbot.yml run --rm userbot --check
    SALES_USERBOT_ENABLED=true docker compose -f ops/userbot/docker-compose.userbot.yml up -d
    docker compose -f ops/userbot/docker-compose.userbot.yml logs -f

`--check` ничего не меняет. Флаг передаётся переменной окружения: compose
читает `.env` рядом с compose-файлом, а не корневой.

## Откат

    docker compose -f ops/userbot/docker-compose.userbot.yml down

Уже отправленное остаётся отправленным — это факт доставки.

## Что осталось вне этого сервиса

- права бизнес-подключения (`can_reply`, `is_enabled`) приложение не сохраняет;
- канал ответа выбирается по факту отказа, а не заранее по источнику лида;
- отправитель умеет только текст и только личным пользователям, не группам.
